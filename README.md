## 🎮 Guess the Output

  **Can you predict the output?**

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[] = {10, 20, 30, 40};
    cout << *(arr + 2) << endl;
    cout << *(2 + arr) << endl;
    return 0;
}
```

<details>
<summary>Reveal the answer</summary>

```text
30
30
```

**Explanation:**

`arr + 2` points to the third element of the array, and `*(2 + arr)` is exactly the same expression because pointer addition is commutative.

</details>
